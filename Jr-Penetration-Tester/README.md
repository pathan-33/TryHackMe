# Junior Penetration Tester — Learning Notes & Progress

This folder contains my hands-on lab notes, commands, methodology, and room walkthroughs for the **Junior Penetration Tester (Jr Pentester)** path on TryHackMe.

My focus here is developing a structured approach to practical offensive security:
* **Recon & Enumeration:** Learning how to properly scan networks and web apps without blindly throwing exploits.
* **Web Hacking & Burp Suite:** Getting hands-on with real-world vulnerabilities (SQLi, XSS, SSRF, IDOR, authentication bypasses).
* **Privilege Escalation:** Escalating privileges on both Linux and Windows systems.
* **Active Directory & Networks:** Testing core AD misconfigurations and lateral movement.
* **Challenges & CTFs:** Putting all the concepts together in standalone challenge machines.
